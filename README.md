# MicVolumeGuard

Трей-утилита для Windows: удерживает громкость микрофона на заданном уровне.

## Возможности
- Иконка в системном трее с **процентом громкости** прямо на иконке.
- Задание уровня громкости (0–100 %) через слайдер/поле в настройках.
- **Блокировка уровня**: изменения от других программ (мессенджеры, игры, система)
  мгновенно откатываются к заданному значению (колбэк WASAPI + watchdog каждые 1.5 с).
- Выбор микрофона (по умолчанию — устройство связи).
- Опциональное удержание состояния mute.
- **Автозапуск вместе с Windows** (HKCU Run — без прав администратора).
- Настройки: `%APPDATA%\MicVolumeGuard\settings.json`.
- Один экземпляр приложения; запуск без прав администратора.

## Сборка
Требуется .NET 8 SDK. Команда:

```bash
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Результат: `bin/Release/net8.0-windows/win-x64/publish/MicVolumeGuard.exe`
(самодостаточный — .NET не требуется на целевой машине).

## Использование
1. Запустите `MicVolumeGuard.exe` — появится иконка в трее.
2. Клик по иконке (левой кнопкой) → окно настроек.
3. Выберите микрофон, задайте громкость, включите блокировку → «Применить».
4. Автозапуск включается галочкой в настройках (или вручную: ярлык в
   `shell:startup`).

## Сборка на Linux
Проект настроен с `EnableWindowsTargeting=true`, поэтому `dotnet publish -r win-x64`
работает прямо из Linux — Windows-машина для сборки не нужна.
